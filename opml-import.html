Simple Wire — Moving Your Feeds In

Last updated: August 25, 2026

If you already read feeds somewhere else, you don't have to retype anything. Nearly every RSS reader — Feedly, Inoreader, NetNewsWire, Reeder, Feedbin, NewsBlur, The Old Reader, and most others — can export your subscriptions as an OPML file, and Simple Wire reads it directly.

The short version

  1. Export an OPML file from your current reader.
  2. In Simple Wire, open Settings → Feeds → Import OPML…
  3. Pick the file. Your feeds appear, folders and all, and start fetching straight away.

If you're setting up Simple Wire for the first time, the welcome screen offers Import OPML as well — same thing, one step earlier.

Getting the file out of your current reader

These paths were accurate when this page was written, but apps move their menus around. If one doesn't match what you see, look for a section called Import/Export, Subscriptions, or Backup in that service's settings — the export is almost always there, and it's almost always free.

Feedly

On the web, go to feedly.com/i/opml and choose Download OPML. The Feedly mobile apps don't offer the export, so use a browser — on an iPhone or iPad that's fine, the file lands in Files.

Inoreader

On the web, open Preferences → Import/Export and use Export subscriptions under the OPML heading.

NetNewsWire

On Mac, File → Export Subscriptions…. On iPhone or iPad, Settings → Import/Export Subscriptions.

Reeder

Reeder syncs with an account elsewhere — iCloud, Feedbin, Inoreader, and so on. If it does, export from that service instead, since that's where the real subscription list lives. If you use Reeder on its own, its settings include an OPML export.

Feedbin, The Old Reader, NewsBlur, Bazqux, FreshRSS

All of these keep an OPML export in their web settings, under Import/Export or a similarly named section.

Google Reader-era backups

An OPML file from any year still works. The format has barely changed since 2000, and Simple Wire doesn't care how old the file is.

Importing on iPhone or iPad

When you download an OPML file in Safari on iOS, it goes to Files → On My iPhone → Downloads (or iCloud Drive, depending on your Safari settings). In Simple Wire, tap Import OPML…, then browse to it there.

If the file arrived as an email attachment, tap and hold it, choose Save to Files, then import it from Simple Wire. Simple Wire accepts .opml, .xml, and plain-text files.

What comes across — and what doesn't

OPML is a list of subscriptions. That's all it has ever been, in any reader. So:

  • Comes across: every feed's address, its title, and the folder it was in.
  • Doesn't come across: which articles you'd already read, your starred or saved items, and any tags or highlights. No reader can transfer those through OPML — the file simply has nowhere to put them.
  • Doesn't come across: usernames and passwords for private feeds. If you subscribe to a feed that requires a login, add it again in Simple Wire with Requires username & password switched on. Credentials are never written into an OPML file by any reader, which is a good thing.

Expect your first refresh to show a large number of unread articles. Nothing is wrong — Simple Wire has no way to know what you'd already read elsewhere. Open the list, pull up past the last article, and release to mark the whole thing read. Then start clean.

Folders

Folders come across with their names intact. One thing to know: if your old reader let you nest folders inside folders, Simple Wire flattens that to a single level, and a feed lands in the innermost folder it was in. A feed filed under News → Technology arrives in a folder called Technology. Feeds that weren't in any folder land under Uncategorized, where you can file them later.

No limits

Every feed in the file is imported, however many there are, with its folder structure. You don't need to unlock anything to import.

Importing more than once is safe

Simple Wire skips any feed whose address it already has, and tells you how many it skipped. So you can import a second OPML from another service, or re-import the same file after unlocking, without ending up with doubles.

One edge case: matching is by exact feed address. If two files list the same feed with slightly different addresses — one http and one https, say, or one with a trailing slash — they'll come in as two subscriptions. Delete whichever one you don't want from Settings → Feeds → Manage Feeds.

If something goes wrong

“No feeds found in that OPML file.”

Usually one of three things. The file may still be zipped — some services deliver the export inside a .zip, so unzip it first and import the OPML inside. It may be an HTML page rather than the file itself, which happens when a download is saved from a page that required a login. Or the export may genuinely be empty, which is worth checking back in the original service.

“Couldn't read that file.”

The file couldn't be opened from where it's stored. Copy it into Files → On My iPhone → Downloads, or onto your Mac's desktop, and import it from there.

A feed shows “Feed unreachable”

The subscription imported fine, but that address no longer responds. Sites move or retire their feeds, and an old OPML can carry addresses that stopped working years ago. Simple Wire keeps retrying on its own. If it never recovers, delete the feed and add the site again by its web address — Simple Wire will find the current feed itself.

Taking your feeds back out

The same door works in both directions. Settings → Feeds → Export OPML… writes a standard OPML file with your feeds and folders, which any other reader can import. There's no lock-in here, and no step where your subscription list stops being yours.

One note about older shared articles

Not a migration question, but it comes up alongside one, so it lives here.

When someone shares an article with you, Simple Wire opens it as an article — the sender's copy of the text, without the publisher's page furniture. That's faster, and on sites that cut their feeds short it's often more readable than the live page.

Shares sent from older versions of Simple Wire carry only a title and a link, because earlier releases didn't send the article text along. Those open the publisher's web page instead, since there's nothing else to render. Nothing is broken, and it can't be repaired after the fact — the text was never sent. Ask the sender to share it again from a current version and the new copy will open as an article.

Either way you're one tap from the other view: the Reader Mode button in the toolbar fetches the full article from the site, and Settings → Shared articles open as lets you make Web Page the default if that's what you prefer.
